# Video Streaming Concurrency & Analytics Dashboard

The dataset is provided in the [`data/`](./data) directory:

- `data/events.csv` — raw telemetry events
- `data/content.csv` — video dimension table

## How to submit

1. **Fork** this repository to your own GitHub account (click the **Fork** button at the top right of the repo page).
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```
3. **Create a sub-directory** at the repository root named using the exact format `<name>-<reg-no>` (for example, `john-doe-24BCE1234`). All of your application files — frontend, backend, config, and docs — must be placed strictly inside this sub-directory.
4. **Add a `README.md`** in the root of your sub-directory with clear, step-by-step local setup instructions and a prominent link to your video demo.
5. **Commit and push** your work to your fork:
   ```bash
   git add <name>-<reg-no>/
   git commit -m "Add submission for <name>-<reg-no>"
   git push origin main
   ```
6. **Open a Pull Request** from your fork's branch back to this repository:
   - Go to your fork on GitHub.
   - Click **Compare & pull request**.
   - Set the base repository to this repo and the base branch to `main`.
   - Give the PR a clear title (e.g. `Submission: <name>-<reg-no>`) and submit.

Your submission is complete once the Pull Request is raised against this repository.

> A working video demonstration is mandatory. Follow the video guidelines in the problem statement and include the link prominently in your sub-directory's `README.md`. Without a video demo, your project will not be reviewed.
